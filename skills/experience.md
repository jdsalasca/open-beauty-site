# Experience skill

Use `beauty_create_experience` for a place, not a landing page. A restaurant, a museum, a history room, a studio or a club. The output is a single-file sequence of **rooms**: each room has a scene, a short text, optional objects and a door to the next.

Read `beauty_get_skill({ format: "experience" })` and `beauty_get_style` before writing the brief.

## The shape

```json
{
  "style": "papercraft",
  "kind": "restaurant",
  "title": "Casa Perla",
  "tagline": "Cocina de mercado, vino de barrio y una mesa para quedarse.",
  "intro": "Una sola carta, tres tiempos y la luz de la tarde.",
  "brand": "CASA PERLA",
  "hours": "Mar–Sáb · 12:00–15:00 / 19:30–23:30",
  "address": "Pasaje del Mercado 14",
  "rooms": [
    { "kicker": "La casa", "title": "Una puerta, una mesa larga", "body": "La cocina se ve desde la calle. El fuego también.", "display": "scene" },
    { "kicker": "La carta", "title": "Tres tiempos, un mercado", "body": "La carta cambia cuando cambia el mercado.", "display": "menu", "items": [
      { "label": "Entrada", "value": "01", "detail": "Tomates asados, ricotta, albahaca quemada." },
      { "label": "Principal", "value": "02", "detail": "Pesca del día, papas nuevas, limón en sal." }
    ] },
    { "kicker": "La noche", "title": "El vino que sobra", "body": "La última botella se abre para quien todavía quiere conversar.", "display": "quote", "quote": { "text": "La mesa se levanta cuando la conversación termina.", "author": "Casa Perla" } }
  ],
  "cta": { "label": "Reservar", "href": "https://example.com/reservas" }
}
```

## Rules

- **3–8 rooms.** One idea per room. If a room needs more than 120 words, it is two rooms.
- The first room is an entrance, not a summary; the last is an exit, not a contact form.
- Use `display` to change the reading: `scene`, `menu`, `exhibit`, `timeline`, `quote`, `objects`.
- Use `items` for things a visitor needs: dishes, objects, dates, capacities. Do not invent prices, allergens, dates or attributions.
- `hours`, `address` and `source` are visible facts. If you do not have them, omit them; never invent them.
- The room rail and keyboard numbers are generated. Do not add custom navigation.
- One scene per room is generated by the style. Do not ask for a stock photo or an external illustration.

## Recipes

### Restaurant

Entrance (the room, the light) → market/menu (3–6 dishes with explicit prices or no prices) → a ritual or a quote → exit (hours, address, reservation link). Voice: concrete, hospitable, no "experiencia gastronómica única".

### Museum

Entrance (the question) → 3–5 objects in `exhibit`/`objects` with date, medium and source → a quiet quote → exit (what to carry, credits). Never invent provenance. A museum is a sequence of looking, not a product page.

### History

Entrance (a date and a place) → 3–5 rooms as turning points with `timeline` items → a primary voice → exit (source and one open question). Distinguish what happened from what is interpreted.

### Studio / club / garden

Entrance → 2–4 rooms of work or atmosphere → a pause → exit (visit, hours, contact). Use the scene more than the copy.

## Self-check

1. Can you walk the rooms with only the keyboard?
2. Does each room change what you know or feel?
3. Does every object have a source or an explicit "unknown"?
4. Is there a reason to stay after the first screen?
5. Does the page still work with animation off and JavaScript off?

If the answer to 2 or 5 is no, it is a landing with more sections.
