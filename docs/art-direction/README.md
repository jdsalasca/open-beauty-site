# Art direction contract

Machine-readable contract: `src/styles/art-direction.ts` exports `ART_DIRECTION: Record<StyleSlug, ArtDirection>`. Human-readable mirrors: `docs/art-direction/<style>.md`, regenerated by `pnpm art-direction:docs` (do not edit by hand).

## How an agent uses it

1. Read `ART_DIRECTION[style]` for intent, composition, typography, color, materiality, illustration, motion, negative rules and adaptation.
2. Check `negativeRules` before generating; reject compositions that violate them.
3. Use `adaptation.web|slides|gif.description` plus the `example` path as the reference for that format.
4. For papercraft, choose `profiles.editorial` (available) or `profiles.friendly` (spec only, `available: false`).
5. Fonts named in `typography.families` must be either bundled (see `fonts/FONTS.md` and `src/narrative/fonts.ts`) or explicitly marked unavailable.

## Consumed vs. guidance only

Most of the contract is **not** imported by the renderers today, except `color.semanticStates` in the page composition layer (`src/page/composition.ts`). Engines consume `StylePreset` (`src/styles/presets.ts`), `TypeSystem`/`MotionSystem` (`src/styles/design-language.ts`) and `SUBFAMILIES` (`src/styles/subfamilies.ts`). Fields below are guidance unless noted.
