# Stage C · índice combinado de galería narrativa GIF

Este índice reúne las 13 escenas y sus dos composiciones canónicas. El corpus contiene 26 combinaciones, además de un ejemplo comparativo adicional por cada piloto (28 paquetes en total). Cada paquete enlaza su brief, GIF, PNG, hoja de contacto y manifiesto.

Los ejemplos están en español y no convierten una propuesta editorial en una afirmación de producto: in-review termina en **Resultado esperado** y done en **Resultado observado**. La revisión visual independiente permanece pendiente; los manifiestos conservan visual-review: pending y recomendación none.
